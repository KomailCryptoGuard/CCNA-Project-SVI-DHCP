# CCNA Project 01 – Enterprise Network Deployment Using SVI & DHCP

## 📖 Overview
This project demonstrates the implementation of an enterprise-style network using *Switch Virtual Interface (SVI)* and *Dynamic Host Configuration Protocol (DHCP)* in Cisco Packet Tracer. The network is designed to provide centralized switch management and automatic IP address assignment to client devices.

## 🎯 Project Objectives
- Configure a Cisco router as a DHCP server.
- Configure Switch Virtual Interface (SVI) for switch management.
- Assign management IP addresses to all switches.
- Automatically assign IP addresses to client devices.
- Verify end-to-end network connectivity.

## 🖥️ Network Topology
- 1 × Cisco 2911 Router
- 4 × Cisco 2960 Switches
- 12 × PCs
